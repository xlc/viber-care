# Legacy Word Garden V2 Content

This directory archives the previous object-pack content model and generated
assets. It is not runtime content.

Active story packs now live in `content/story-packs/`, and the app catalog must
not import files from this legacy archive.

Use this material only as manual source material when creating new story packs.
Copy any reused image or audio assets into the active story pack's public asset
directory after review.
