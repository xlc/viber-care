# Word Garden Game Description

Word Garden is a gentle bilingual word-learning game for toddlers. It is built around looking, listening, tapping, dragging, and naming familiar objects in calm illustrated scenes. The game should feel like a soft digital toy: there are no scores, timers, punishments, ads, purchases, or harsh failure states.

The current game includes 8 content packs, 135 learning items, 21 scenes, and 9 smaller selectable sets. Every learning item supports English and Simplified Chinese.

The next major product direction is Math Play: a fifth mode that teaches early quantity, matching, sorting, comparison, and spatial language through action. Math Play should reuse the same static packs and gentle scene style, but it should stop treating numbers as only friendly number-card objects. A toddler should be able to put two apples in a basket, give each duck one seed, match three dots to three fish, choose the plate with more bananas, sort red fruit into a red basket, and hear natural English and Simplified Chinese counting phrases.

## Core Play

The child plays inside a calm scene filled with friendly objects. A prompt ribbon at the top of the play area shows the current word, prompt, or response. When sound is enabled, the game speaks the same learning phrase aloud.

Each scene contains more possible objects than it shows at once. A round displays a smaller group of objects so the same scene can feel slightly different across play sessions. Objects appear in appropriate parts of the scene: fish in water, birds in sky or trees, vegetables in garden beds, letters on cards, and vehicles on road, rail, water, or sky areas.

Every object has at least two friendly visual versions, so a child may see a classic version in one round and a brighter or larger version in another. Objects also have soft animation personalities such as bobbing, bouncing, swaying, glowing, or wiggling.

## Game Modes

### Explore

Explore is open-ended free play. The child taps any visible object and the game names it using the selected language and word-detail setting. Every tap is accepted.

Explore is designed for curiosity rather than instruction. A child can tap a duck, dog, sun, train, number, letter, or dinosaur in any order and hear the word or phrase without being corrected or redirected.

### Find
w
Find gives the child a gentle listening task, such as "Find the duck" or "Find number one." The prompt can be shown and spoken in English, Simplified Chinese, or both.

When the child taps the requested object, the game celebrates with a soft success phrase and then moves to the next target. When the child taps a different object, the game names that object first and then repeats the original prompt. It never says the child is wrong.

### Puzzle

Puzzle is a drag-only matching mode. The scene shows empty object spots, and the tray shows movable object pieces. The child drags each piece from the tray to the matching spot in the scene.

When a piece matches its spot, it settles into the scene and the game speaks a success phrase. If a piece is dropped somewhere else, the piece simply returns and the game names it. After all pieces are placed, the puzzle refreshes gently with the same scene and a new tray order.

### Cards

Cards turns the selected pack into a simple object deck. Each card shows one large object image and its current word or phrase. The child or parent can move forward and backward through the deck and replay the spoken phrase.

Cards are useful for slower naming practice, parent-guided repetition, and reviewing a whole pack without searching inside a scene.

### Math Play

Math Play is the planned fifth mode. It should be built as part of Word Garden, not as a separate app. It should rotate tiny early-math mini-games that use the same content packs, object art, scene regions, static audio, and bilingual language model as the rest of the game.

Math Play is not a drill mode. It should feel like feeding, collecting, matching, sorting, and pretend play. There should be no score, timer, lives, badges, streaks, or visible achievement pressure. Every round should be short, calm, and forgiving. If the child taps or drops something unexpected, the game should name what happened and gently continue: "That is one apple. We need one more." It should never say "wrong."

Math Play should reduce visual load compared with Explore:

- First rounds should usually use 1 to 3 target objects.
- Normal toddler rounds should use 1 to 5 target objects.
- Quantities 6 to 10 should be treated as optional stretch practice behind parent settings.
- Choices should start at 2 options and only grow to 3 or 4 when the child is comfortable.
- Objects should be larger and more evenly spaced than vocabulary objects in a busy scene.
- Counting rounds should avoid clutter because the child needs to visually track one-to-one actions.

The first Math Play release focuses on four mini-games:

- Count and Collect: implemented first; put a requested quantity of objects into a container.
- Feed the Friend: MVP follow-up; give a friend a requested quantity of food or objects.
- Dot Match: MVP follow-up; match a dot card to the object group with the same quantity.
- Color Sort: MVP follow-up; place objects into matching color baskets.
- Shape Sort: metadata-ready, but pending committed shape-capable content.

Later Math Play rounds can add More/Less/Same, Number Path Hop, Pattern Train, Big/Small, Where Is It, and Count the Sounds.

## Learning Progression

The parent can choose how much language the game presents. The same object can be introduced as a single word or expanded into short phrases and tiny scene sentences.

- Single word: one clear name, such as "duck" or "鸭子."
- Tiny phrase: a short descriptive phrase, such as "The duck says quack."
- Short label: two or three words that add context.
- Simple sentence: one calm sentence about the object.
- Question: a prompt-and-answer style line.
- Little scene: a short narrated line that places the object in the world.

The parent can also choose the language order:

- English only.
- Simplified Chinese only.
- English then Simplified Chinese.
- Simplified Chinese then English.

Math Play should add a separate learning-focus progression that is independent from vocabulary word detail. A child can use single-word vocabulary while still practicing counting 1 to 3, or use richer object language while staying in easy math rounds.

The planned Math Play progression bands are:

- First Math: quantities 1 to 2, no numerals required, objects and dots first, two choices maximum, count aloud during actions.
- Growing Math: quantities 1 to 5, dots plus objects, simple more/less/same, color sorting, and shape sorting.
- Big Kid Stretch: quantities 1 to 10, numerals plus dots plus objects, number path order, one more/one less, and simple AB patterns.

The parent should be able to lock Math Play to First Math or Growing Math so younger children are not pushed into stretch content.

Math Play should adapt quietly behind the scenes. It should track comfort level, not achievement. If the child completes several 1-to-3 rounds smoothly, the mode can introduce 4 or 5. If the child taps randomly or repeatedly avoids a task, it should reduce choices and return to 1 or 2. If a child struggles with numerals, it should keep using dots and object groups first. Any adaptation should stay invisible to the child.

For Math Play, visible progress language belongs in parent settings only. The child should not see badges or scores. A parent-facing summary can say things like "Recent practice: counting 1-3, color sorting, matching dots to objects."

## Math Play Content Model

Math Play should extend existing content with optional metadata rather than hard-coding math behavior in the engine. Raw content should remain in committed `content/packs/*.json` files, imported through `src/content/catalog.ts`. The runtime must stay static-only.

Each object can opt into math use with optional fields that describe how it can be counted, sorted, compared, or placed. The exact schema can evolve, but the metadata should cover these concepts:

- Whether the object is countable.
- Whether multiple copies can be shown in one round.
- Category, such as animal, fruit, vegetable, vehicle, shape, color, toy, nature, or food.
- Available colors, such as red, yellow, blue, green, orange, purple, black, white, or brown.
- Size variants, such as big and small.
- Scene zones where the object makes sense, such as sky, water, road, rail, garden bed, tree, basket, plate, pot, or pond.
- Supported math skills, such as counting, one-to-one, dot matching, comparison, sorting, spatial placement, patterning, or size comparison.
- Quantity range, usually 1-3, 1-5, or 1-10.
- Simplified Chinese measure word, such as 个, 只, 条, 辆, 朵, 颗, 根, or 张.
- English singular and plural forms when the default word cannot be pluralized mechanically.
- Natural bilingual prompt and success templates when an object needs special wording.

The engine should use these optional fields to build rounds, but absence of math metadata should not break normal Explore, Find, Puzzle, or Cards play. Objects without math metadata can remain vocabulary-only.

Math Play needs reusable quantity groups. The implementation should not require a separate hand-drawn image for every quantity. It can reuse the same static object variant multiple times with gentle layout differences:

- Slight position offsets.
- Slight scale variation.
- Small rotation where appropriate.
- Clear spacing so each item can be counted.
- No overlap that hides the true quantity.

Quantity groups should be generated at runtime from committed static object images, not by loading remote content or calling AI. If a grouped illustration is added as a static asset, it should still be committed under `public/assets/` and referenced from the content pack.

Recommended first quantity-capable objects:

- Apples, bananas, carrots, flowers, balls, ducks, fish, frogs, rabbits, seeds, leaves, shells, cars, trucks, and eggs.
- Dot cards with 1 to 5 large dots first, later 1 to 10.
- Simple containers such as basket, plate, pond, pot, bowl, mat, and feeding spot.

Math Play rounds should respect scene regions just like vocabulary placement. Fish should remain in water, birds on trees or sky, vehicles on road/rail/water/sky as appropriate, and vegetables in garden or basket areas. Counting should not create nonsensical placements just because an object is countable.

## Math Play Mini-Games

### Count and Collect

Prompt examples:

- "Put 3 apples in the basket."
- "Find 2 ducks."
- "Put 3 fish in the pond."

The child taps or drags objects one at a time into a target area. Each successful placement is counted aloud. After the final item, the game says the total.

English example:

- "One... two... three. Three apples!"

Simplified Chinese example:

- "一...二...三。三个苹果！"

This round teaches counting sequence, one-to-one action, and cardinality. The final total matters: the child learns that the last count word tells "how many."

### Feed the Friend

Prompt examples:

- "Give the bunny 2 carrots."
- "Give the duck 2 seeds."
- "Give the baby dinosaur 1 leaf."

The child moves one food item at a time to the friend. The friend can smile, bob, or make a soft happy sound after each item. The game counts each item as it arrives and ends with a natural total phrase.

This round is especially good for one-to-one correspondence because one item maps to one physical action.

Good pairings:

- Bunny and carrots.
- Duck and seeds.
- Baby dinosaur and leaves.
- Fish and bubbles.
- Cow and hay.
- Frog and flies, only if the art stays friendly and non-scary.

### One for Each

Prompt examples:

- "Give each duck one flower."
- "Put one seed by each bird."
- "One carrot for each bunny."

Several friends appear, and the same number of items appears nearby. The child places one item near each friend. The goal is fairness and matching, not only reciting numbers.

This round teaches one-to-one correspondence, equal groups, and early division-like thinking without formal math language.

### Dot Match

Prompt examples:

- "Find 3 dots."
- "Match 3 dots to 3 fish."
- "Which group has 2?"

The game shows a large dot card and two or three object groups. The child matches the dot card to the group with the same quantity.

Dots should come before numerals. Later rounds can show both a numeral and dots, such as a "3" card with three dots.

### More, Less, Same

Prompt examples:

- "Which plate has more bananas?"
- "Which bowl has fewer apples?"
- "Do these have the same number?"

The first rounds should be visually obvious: 1 banana versus 3 bananas, or 2 fish versus 5 fish. Later rounds can compare closer quantities.

The mode should use simple language:

- "More bananas."
- "Same number."
- "These are the same."
- "This plate has more."

### Number Path Hop

Prompt examples:

- "Tap the next number."
- "Hop to 3."
- "What comes after 2?"

A frog, bunny, train, or dinosaur moves along a short path: 1, 2, 3, 4, 5. The child taps the next number, and the character moves forward with a soft sound.

This round teaches number order. It should start with 1 to 5. The 1-to-10 path belongs in Big Kid Stretch.

### Shape Sort Garden

Prompt examples:

- "Put circles in the round basket."
- "Find the triangle."
- "Put the star on the star mat."

Start with circle, square, and triangle. Add star and heart later. Shapes should be large, friendly, and clearly different. The game should avoid tricky rotations or near-identical shapes in early rounds.

### Color Sort Picnic

Prompt examples:

- "Put red fruit in the red basket."
- "Put yellow bananas on the yellow plate."
- "Find the blue fish."

Use real objects instead of abstract color blocks. Begin with two colors, such as red apples and yellow bananas. Later use blue fish, orange fish, green leaves, and purple flowers.

This strengthens vocabulary while teaching classification.

### Pattern Train

Prompt examples:

- "What comes next?"
- "Cow, sheep, cow, sheep..."
- "Red, blue, red, blue..."

Start with simple AB patterns only. A train can show cow, sheep, cow, sheep, blank. The child chooses between cow and sheep. Later rounds can use sound patterns such as quack, moo, quack, moo.

### Big and Small

Prompt examples:

- "Find the big apple."
- "Put the small fish in the pond."
- "Which truck is big?"

This teaches early measurement language. Supported word pairs should include:

- big / 大
- small / 小
- long / 长
- short / 短
- full / 满
- empty / 空

### Where Is It?

Prompt examples:

- "Put the bird on the tree."
- "Put the fish under the bridge."
- "Put the ball in the basket."

This teaches spatial language. Early spatial words should include:

- in / 里面
- on / 上面
- under / 下面
- next to / 旁边
- above / 上方
- below / 下方

Spatial prompts must respect scene regions and should be visually obvious.

### Count the Sounds

Prompt examples:

- "How many quacks?"
- "Tap 2 ducks."
- "Which card has 3 sounds?"

The game plays one to three soft sounds, and the child picks a matching dot card or taps the same number of icons. This should be optional because audio-only tasks can be harder for toddlers. The sound must be repeatable, soft, and never surprising.

## Math Play Language

Math Play prompts should stay short during play:

- "Find 2 ducks."
- "Put 3 apples in."
- "One for each bunny."
- "Which has more?"
- "Tap the next number."
- "Big apple."
- "Small apple."

After the action, the game can use a fuller phrase:

- "You found two ducks."
- "Three apples in the basket."
- "Great counting."
- "One, two. Two ducks."
- "一，二。两只鸭子。"

Longer explanations belong in Cards or parent co-play prompts, not in the child-facing round.

Simplified Chinese counting should use natural measure words. The game should not only say a number sequence and then an object name. It can count simply first, then state the natural total:

- "一...二...三。三个苹果。"
- "一...二。两只鸭子。"
- "一...二...三。三朵花。"
- "一...二...三...四。四条鱼。"
- "一...二...三...四...五。五辆车。"

Recommended measure words:

- 个: apples, balls, simple generic objects.
- 只: ducks, birds, rabbits, many animals.
- 条: fish and long flexible animals.
- 辆: cars, trucks, buses, vehicles with wheels.
- 朵: flowers.
- 颗: small round objects, seeds when appropriate.
- 根: carrots, bananas, sticks, long vegetables.
- 张: cards, dot cards, flat paper-like items.

Use 两 for "two" in natural quantity phrases when appropriate:

- 两只鸭子, not 二只鸭子.
- 两辆车, not 二辆车.
- 两朵花, not 二朵花.

The count sequence can still use 二:

- "一，二。两只鸭子。"

This gives toddlers both the counting sequence and natural Mandarin phrasing.

## Parent Co-Play

Math Play should make parent participation easy without crowding the child-facing game. Parent prompts should be quiet and optional, ideally behind the gear button or a small parent-only "Co-play Ideas" control.

Example co-play prompts:

- "Ask: How many apples are in the basket?"
- "Try saying: one apple, two apples."
- "Now find two real toys nearby."
- "Count 3 blocks together."
- "Put one spoon by each bowl."
- "Find something big and something small in the room."
- "Make a red, blue, red, blue pattern with toys."

The parent page can add a "Learning Focus" setting with choices:

- Vocabulary.
- Counting 1-3.
- Counting 1-5.
- Colors.
- More/Less.
- Spatial Words.
- Patterns.
- Mixed Gentle Play.

These settings should guide round selection only. They should not create pressure or visible goals for the child.

## Math Play MVP

The recommended first release is "Counting Garden." It should use the existing Word Garden, Farm Friends, Fruits and Vegetables, and Ocean Animals packs where possible.

Initial round examples:

- Put 2 apples in the basket.
- Give the bunny 1 carrot.
- Put 3 fish in the pond.
- Match 2 dots to 2 ducks.
- Put red flowers in the red pot.
- Put circles in the round basket.

Optional follow-up rounds after the MVP:

- Find the plate with more bananas.
- Put the bird on the tree.
- Tap the next number.
- What comes next: cow, sheep, cow, sheep?
- Find the small fish.

The MVP should prioritize 1 to 3. It can include 4 and 5 only after the core interaction feels calm and readable.

Implementation expectations:

- Add Math Play as a first-class mode alongside Explore, Find, Puzzle, and Cards.
- Add a separate round engine for math templates instead of mixing math-specific branching into Find or Puzzle.
- Reuse the existing drag-and-drop library for drag rounds.
- Keep tap support for Math Play where it improves toddler accessibility, even though Puzzle itself remains drag-only.
- Use static content metadata and committed assets only.
- Keep all child-facing wording bilingual through content or shared language templates.
- Do not add runtime AI, backend calls, remote content, analytics, or client secrets.
- Do not add generated runtime catalogs or content generation package scripts.
- Keep validation generic and schema-focused.

Acceptance criteria for the first Math Play release:

- A child can enter Math Play from the mode selector.
- The first rounds use quantities 1 to 3.
- Count and Collect, Feed the Friend, Dot Match, and Color Sort are playable.
- Shape Sort is not required until committed shape-capable content exists.
- A successful counting action speaks each count and then the total.
- Simplified Chinese totals use natural measure-word phrases.
- Unexpected taps or drops produce gentle continuation, not failure language.
- The visual scene is less cluttered than Explore.
- Mute still applies to all spoken math prompts.
- Parent settings can choose or limit the learning focus.
- Existing Explore, Find, Puzzle, and Cards behavior remains intact.

## Toddler-Safe Interaction Rules

Word Garden keeps the mood soft and forgiving.

- Every object interaction gives useful feedback.
- A missed Find tap names the tapped object instead of saying "wrong."
- Puzzle mismatches return gently and still reinforce the object name.
- There are no countdowns, scores, lives, penalties, ads, or purchase prompts.
- Sound can be muted at any time.
- Parent settings stay behind the gear button.
- Tap and drag targets are large and simple.
- Motion is slow, playful, and low-pressure.
- Math Play should track comfort internally, not show scores or achievement pressure.
- Math Play should reduce difficulty when a child seems overwhelmed.
- Math Play should introduce harder quantities only when the child is comfortable.

## Expected Play Session

A typical session starts in Explore mode with the default Word Garden pack. A toddler taps a few objects, hears names in English and Simplified Chinese, and watches the objects move gently. A parent may switch to Find mode for guided listening, Puzzle mode for drag-and-match practice, Cards mode for calmer review, or Math Play for short action-based counting and sorting rounds.

The same content can support different moods: free discovery, prompted recognition, hand-eye matching, quiet vocabulary review, and early math play. The goal is not to test the child, but to surround them with repeated, friendly word-object, quantity, shape, color, and spatial connections.
